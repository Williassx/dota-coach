# Очередь задач Dota Coach

Версия: 9 октября 2026 года. Основание: [план](roadmap.md) и [замысел](project-brief.md).
Таблица DC описывает общие результаты продукта. Актуальная очередь по владельцам —
[две библиотеки и 72 подпункта](../creators/README.md); статусы находятся в их README.
Начат C1-01-01 (диагностика), игровые функции пока не объявлены выполненными.
Исполнитель и ревьюер обозначены номерами из [каталога](agents.md).
Подробные файлы, сигнатуры и команды проверки будут определены в планах подсистем.

Предыдущая очередь MVP-01–23 сохранена в [архиве](archive/2026-10-08-backlog.md)
и заменена очередью DC-001–DC-048. Старые номера не переиспользуются.

## Выполнение и параллелизм

- DC-011–13 и DC-014–18 идут независимо после DC-010 и контрактов данных.
- DC-027 можно исследовать параллельно с DC-022–26 после определения команд.
- DC-037 можно делать вместе с DC-033–36 после общей спецификации экрана и состояния.
- Изменения общих типов и правил координируются владельцем интерфейсов (146).
- Для ML, парсинга реплеев и распознавания речи назначаются дополнительные компетенции
  внутри ведущих ролей; номер в каталоге не подтверждает наличие готовой модели или инструмента.

Формат рабочей карточки: ID → статус → входные интерфейсы → разрешённые файлы →
точные критерии → команды проверки → результат → проверяющий. Статусы:
запланировано, готово к выполнению, выполняется, проверяется, завершено, заблокировано.
Готовность к выполнению требует завершённых зависимостей и рассмотренного плана подсистемы.
При внешнем блокере данных DC-020 фиксирует ограничение; независимые механики
можно выполнять по отдельному рассмотренному плану с синтетическим общим ИИ.
Этот путь не считается выполненной проверкой сходства и не даёт статуса цифрового двойника.

## Особые проверки

Ошибочная идентификация игрока; несовместимый патч; пропуски данных; отсутствие
наблюдений по выбранному герою; утечка будущего или скрытой информации; смена режима
во время смерти; покупка без ресурсов; неоднозначный голос; двойное исполнение приказа;
пауза; повторный старт; смена скорости; сброс нового матча; восстановление повторов.
Каждая проверка закрепляется тестом в задаче, которая владеет соответствующим поведением.

## Юридическое направление

[10 задач LGL-001–LGL-010](legal/plan.md) дополняют 48 задач разработки.
DC-003 использует их результаты для архитектурного выбора; DC-047 проверяет
фактические основания на окончательный выпуск. Предварительный отчёт не считается
полученной лицензией. Цель — Dota 2 с собственными тренерскими механиками.
