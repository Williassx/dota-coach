# Каталог агентов Dota Coach

172 специализации ИИ-агентов для разработки симулятора тренера команды Dota 2.
Каталог описывает роли и не запускает процессы автоматически. Один агент может выполнять
несколько ролей; конкретная задача назначается отдельно.
Быстрый доступ по номеру и категории: [Агенты.md](../Агенты.md).

## Концепция

Пользователь собирает команду из персональных цифровых моделей игроков по их матчам,
готовит состав, отдаёт голосовые приказы и временно вмешивается мышью в действия героя.
После вмешательства управление возвращается персональному ИИ.
По исходному эскизу карта находится в центре, пять карточек своей команды — снизу,
противники — сверху, панель приказов и чат — справа.
Формат — видеоигра в реальном времени. Браузер — рабочая рекомендация;
движок и точность симуляции ещё не выбраны.
Актуальные требования: [замысел](project-brief.md), [план](roadmap.md) и
[навыки](skills.md).

## Подключение к работе

- Юридическое направление ведёт координатор (161) с ролями 162–172;
  [план исследования](legal/plan.md) и [первичный разбор](legal/initial-review.md).
- Начинать с координатора (1), геймдизайнера (5), архитектора (7), редактора
  источников (40), архитектора ИИ (51) и аналитика оценки (142).
  После проверки данных подключать симуляцию (41), карту (73) и тестирование (112).
- Подключать владельца MVP (151), чтобы сначала проверить два персональных профиля
  в небольшой сцене, затем собрать матч 5×5 с подготовкой, голосом и вмешательствами.
- Назначать каждой задаче одну ведущую роль. Смежные роли подключать для консультации
  или проверки; не создавать дублирующие реализации.
- При делегировании указывать цель, входные данные, разрешённые файлы, зависимости,
  критерии приёмки и команды проверки. Согласовывать общие интерфейсы до параллельной работы.
- Запускать только роли, необходимые текущему этапу, с учётом доступных слотов среды.
- Различать агентов разработки и игровой ИИ: роли из каталога создают продукт,
  а виртуальные игроки являются частью продукта.

163. **Агент по авторским правам и производным произведениям** — Проверяет карту, героев, модели, текстуры, звуки и изменения оригинальных материалов.
164. **Агент по товарным знакам и названию игры** — Проверяет Dota 2, Valve, логотипы, оформление и представление связи с правообладателем.
165. **Агент по Workshop, пользовательским режимам и платформенным условиям** — Различает права для режима внутри Dota 2, внешней интеграции и самостоятельного выпуска.
166. **Агент по правам на статистику, реплеи и API** — Исследует условия dota2.ru, Valve и других источников на сбор и повторное использование матчей.
167. **Агент по правам игроков на имя и образ** — Исследует использование ников, имён, портретов, голоса и идентичности при представлении цифровой модели.
168. **Агент по персональным данным** — Проверяет применимые правила обработки данных игроков и пользователей, включая записи голосовых команд.
169. **Агент по обучению ИИ и использованию моделей** — Различает права на сбор данных, извлечение признаков, обучение, хранение и распространение моделей.
170. **Агент по договорам и монетизации** — Проверяет лицензии, условия финансирования, договоры с исполнителями и разрешённые способы заработка.
171. **Агент по юрисдикциям и международному выпуску** — Определяет необходимые страны анализа с учётом оператора, игроков, аудитории и распространения.
172. **Агент по подготовке предложения правообладателю** — Готовит пакет для Valve с описанием идеи, перечнем прав и конкретными вопросами; отправка назначается отдельно.
