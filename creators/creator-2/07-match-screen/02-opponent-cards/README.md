Каталог fixtures пока не нужен: малые синтетические входы заданы в тестах.
Новый вложенный каталог получает README с назначением и ссылкой из этого файла.
API, сигнатуры, конкретные файлы и команды проверки закрепляются в локальном
техническом плане после исследования входов; не подменяйте их выдуманными командами.

Клиент принимает минимальный DTO, но не устанавливает право доступа. Политика
C1-09-02 должна предоставлять разрешённую проекцию; `sourceAuthorizationConfirmed=false`.
Локальные проверки не доказывают серверную невидимость врага. Нет выбора соперника,
приказов, entity/camera API, боевых характеристик, общего HUD или установки в Dota.
