# C2-09-02: ограниченная проверка preparation при двух размерах

12 октября 2026. Ведущая роль157; root107/114/159/173/174/175.
Пользователь поручил продолжать самостоятельно по плану. Это повтор существующей
[TEST-сцены подготовки](../../11-integration/01-ui-binding/native-preparation-design.md),
без новой настройки продукта. Разрешения1600×900 и1024×768 — точки опыта,
а не утверждённый список поддерживаемых экранов.

Использовать уже скомпилированный отдельный addon
`dota_coach_c2_preparation_r1_20261012` только после сверки17compiled hashes,
карты и17installed source payloads с историческим fixture report.
Сопоставить18raw inputs с текущей библиотекой. Не менять addon/источники/настройки
ОС или игры; размеры задавать launch flags каждого собственного временного клиента.

На каждом размере сохранить шесть actual engine кадров bound/team/complete/reset/
disposed/rebound. Actual PNG dimensions должны совпасть с запросом. Проверить:
ширину трёх блоков без обрезания, сохранность колонок, семь подписей controls,
TEST/unknown и предупреждения, нижний край после API scroll, reset/dispose/rebind.
Predicates из существующего драйвера не заменяют визуальный осмотр.

Активный пользовательский ввод может изменить API scroll; такой результат сохранять
как неуправляемый. Состояние mouse/native hittest не исследуется. Просвечивающий HUD,
C1/bootstrap/storage, физический ввод и второй человеческий владелец открыты.
Постоянные настройки не добавлять, общий HUD13/probe policy не расширять.

Один read-only helper уточняет визуальные критерии; root единственный автор.
После завершения одна техническая критическая проверка, usage с неизвестными null,
фактический отчёт и обычная ранее разрешённая публикация.

13октября build_id изменился25845666→25894101. Исторический1600×900 не переносится
на новый runtime; interrupted1024×768 не имеет completed phase evidence. Для нового
1024×768 использовать fresh bundle/addon и три native compile команды. Разные
версии исключают управляемое сравнение влияния только соотношения сторон.
