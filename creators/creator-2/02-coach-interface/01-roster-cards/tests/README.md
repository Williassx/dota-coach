# Проверки карточек

[Подпункт](../README.md) · [roster-cards.test.cjs](roster-cards.test.cjs)

Из корня репозитория:

```bash
node --test creators/creator-2/02-coach-interface/01-roster-cards/tests/roster-cards.test.cjs
```

Исполняются настоящие скрипты в Node VM с моделью панелей и планировщика.
Проверяются обновления, выбор, происхождение профиля, отказы и освобождение
обработчиков. Вызовы игровых команд перехватываются. Малые входы создаются
в тесте; явное демо использует единственный файл `roster_cards_demo_data.js`.
Это не тест Source 2, мыши в клиенте или обученной модели реального игрока.
