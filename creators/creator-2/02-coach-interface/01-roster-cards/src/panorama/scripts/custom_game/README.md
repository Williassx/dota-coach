# Логика карточек

[Скрипты](../README.md) · [Спецификация](../../../../design.md)

- [roster_cards_state.js](roster_cards_state.js) — модель локального просмотра.
- [roster_cards.js](roster_cards.js) — адаптер панелей; `DotaCoachRosterPanels.bind(root)`.
- [roster_cards_demo_data.js](roster_cards_demo_data.js) — два вымышленных профиля.
- [roster_cards_demo.js](roster_cards_demo.js) — отдельный запуск демо и очистка при перезагрузке.

`replace(rows)` получает частные данные представления из спецификации. Серверный
переходник появится после общего контракта; этот интерфейс не задаёт сетевой протокол.
Выбор карточки обозначает просмотр и не посылает команд игрокам.
`isDisposed()` сообщает о закрытии адаптера; демонстрационный watcher освобождает
cache и таймер на следующем тике после ошибки отображения.
