## Результат и приёмка

Клик по панели не превращается в неожиданный приказ карте.

Этот критерий внутри Dota ещё не проверен. Координатор связывает существующие
адаптеры, не устанавливает обработчик мыши карты и не выполняет команды игры.
Новая общая разметка, серверный переходник и ручное вмешательство не подключены.

Каждый root принадлежит одному адаптеру; отдельные demo на тех же панелях
предварительно освобождаются. Снимок обновляет режим, выбор обновляет адресата;
ни один из этих вызовов не отправляет приказ сам по себе.

Проверка из корня репозитория:

```sh
node --test creators/creator-2/02-coach-interface/03-control-input/tests/input-routing.test.cjs
```

Node.js 18+ без внешних пакетов. VM не доказывает нативные попадания мыши,
распространение клика, компиляцию Panorama или серверную авторизацию.
