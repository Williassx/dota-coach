## Как вести журнал

- После каждой законченной задачи или остановки по внешнему ограничению дополняйте
  файл `YYYY-MM-DD.md` за соответствующую дату UTC; новую дату добавляйте в этот индекс.
- Записывайте поручение, ID задачи, фактические действия, изменённые файлы,
  проверки с их результатами, замечания критиков и незавершённые шаги.
- Для опубликованного изменения указывайте commit и ссылку на подробный отчёт.
  Commit самой записи доступен в Git-истории файла; не создавайте второй commit
  только для вставки его собственного хеша.
- Ретроспективные сведения помечайте и подтверждайте историей Git или отчётами.
  Исторические результаты тестов отличайте от проверок текущей задачи.
- Исходники, подробные технические отчёты и статусы не переносите сюда:
  журнал описывает действия и ссылается на их единственные оригиналы.

Формат очередной записи: **поручение → действия и файлы → проверка и результат →
commit/отчёт → что осталось**. Не выдавайте подготовку исходников за запуск игры.
