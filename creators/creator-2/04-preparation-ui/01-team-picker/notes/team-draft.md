# Черновик состава в памяти

[Подпункт](../README.md) · [Дизайн](../design.md).

`DotaCoachTeamPicker.create()` создаёт независимую локальную модель без bootstrap.
`update({revision,profiles})` получает частную проекцию источника, а не server DTO.
Максимум 64 записи, exact поля id/playerName/profileVersion/kind/sourceLabel/coverage
описаны в дизайне. Данные не загружаются автоматически; примеры только в tests.

`choose(id)` выбирает максимум пять разных виртуальных id; `remove(id)`, `clear()`
редактируют выбор. Имена не используются для дедупликации. Один id нельзя выбрать
дважды, даже если источником предлагаются разные версии. Связь id с реальным человеком
будет проверяться C1; разные ключи сами по себе не доказывают разные личности.

`view()` возвращает полные независимые профили каталога и выбора, local status/message,
count/complete и два предупреждения на выбранный id: вид профиля и охват.
`draft()` возвращает null без валидного каталога; иначе catalogRevision/draftRevision,
complete, serverConfirmed=false и только пары id/profileVersion в порядке выбора.
Complete означает ровно пять локальных записей. Нет проверки ролей/героев/патчей,
подтверждения сходства, запуска матча или сохранения после перезапуска.

Снимок с новой ревизией временно делает draft и редактирование недоступными.
High-water обновляется до body decode; отдельный catalogRevision появляется после
commit. Old/duplicate не читают body/keys и не прерывают принятый новый snapshot.
Invalid snapshot очищает каталог/черновик; старый снимок не восстанавливает их.
Новая версия выбранного профиля снимает выбор, возвращение не выбирает автоматически.
Newer reentry и dispose блокируют commit старого getter; invalid reentry тоже прерывает
внешний разбор. Array length фиксируется до цикла и ограничивается 64.

Текст источника — простой текст, не HTML/URL разрешение. player_model и reported
обозначают предоставленную запись/сообщённый охват, не проверенные факты.
DraftRevision меняется только при изменении выбора, защищён от переполнения.
При исчерпании счётчика модель закрывается без wrap; этот практически недостижимый
через public API край проверен чтением source, а не динамическим тестом.

```sh
node --test creators/creator-2/04-preparation-ui/01-team-picker/tests/team-picker.test.cjs
```

Команда проверяет ES5 source в Node VM, а не экран Panorama/Dota.
