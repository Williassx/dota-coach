# План реализации единого прогона

Основание: [design.md](design.md). Работа основного исполнителя в этой папке.

1. Зафиксировать 34 существующих набора и добавить отдельный набор тестов помощника
   в `suite-catalog.json`. Создать тесты каталога, summaries, границ вывода,
   параметров, неперезаписи, timeout/ошибок, полного и целевого CLI; получить RED.
2. Реализовать `tools/run_source_checks.py`: валидировать всё до записи, собирать
   argv без shell, сохранять логи и краткий source-only отчёт, вернуть ненулевой
   код для любого непрошедшего набора. Получить GREEN целевых тестов.
3. Пройти полный каталог одной командой, проверить наличие всех прежних наборов,
   журнал, ссылки и график. Один финальный критик после готового подпроекта.
4. Обновить reusable cloud draft одной проверенной командой вместо длинного списка,
   сохранить остальные поля и проверить чтением. Записать ограничения публикации.
5. Обновить README, отчёт, журнал и учёт без выдуманных token metrics; опубликовать
   нормальным push. Нативную приёмку и проверку другим владельцем не закрывать.
