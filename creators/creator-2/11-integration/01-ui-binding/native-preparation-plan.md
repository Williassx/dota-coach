# План native preparation

[Дизайн](native-preparation-design.md). Рутинные команды выполняются самостоятельно.

1. RED anonymous-root regression в existing preparation package; исправить shell
   и exact outer policy. Fixed15/14, scripts и module inputs не расширять.
2. RED→GREEN isolated fixture builder: bytes/derived graph/input fingerprints,
   deterministic assets, refusal existing/escape/missing/mapping/executable manifest.
3. Driver explicit bind/public DTOs: empty/team/complete/reset/disposed/rebound.
   Фокусировать внешний scroll native API после complete, без mouse callback.
4. Fresh guarded build, absent addon dirs, source→installed hashes, compile active
   manifest, retained generated layout и Valve template_map. Own client1280×720.
5. После фаз engine screenshot, осмотреть actual frames; quit/check own PID.
   При найденных native defects исправить canonical source и проверить новый запуск.
6. Targeted + required full source checks; честные platform failures. Report,
   resume/journal/lessons/usage; graph без необоснованных acceptance checkboxes.
   Один final technical critic и обычная ранее разрешённая публикация.
