# Подготовка source-пакета истории

Из корня репозитория cloud-проверена команда:

```text
python3 creators/creator-2/10-user-testing/01-install-guide/tools/prepare_ui_handoff.py --screen orders-timeline
```

Она вызывает существующие foundation builder/verifier с
[fixed recipe](../orders-timeline-manifest.json), создаёт новую source папку и отдельный
immutable companion report. На Windows launcher выбирается по фактическому аудиту.
Пять canonical ресурсов из C2-07-03, два definitions в одном context, exact10 IDs/
девять пустых plain Labels и hidden root. Все outputs достижимы четырьмя links.

Для явного binding/record/dispose см. [API панели](../../../07-match-screen/03-orders-timeline/notes/panel.md).
Host предоставляет снимки одного Orders instance; bootstrap/synthetic events сюда
не добавлены. Manifest альтернативный Hud, не автоматически общий manifest игры.
Initial Panel.visible расширен локальным trusted caller shared parser; старые
kind defaults и TextEntry запрет сохраняются. Read_source/output/current-source
защита общая. Не изменять generated output и не заменять Steam/Tools installation.
Установка/Source2 compile/native scroll/appearance/игровой эффект не проверены.
