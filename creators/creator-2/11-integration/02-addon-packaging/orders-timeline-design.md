# Source-пакет журнала приказов

Ведущий — создатель2; root реализует самостоятельно. Седьмой fixed kind
`panorama_source_orders_timeline` собирает пять canonical ресурсов C2-07-03:
Hud loader, inert layout, CSS и две JS definitions. Копий редактируемых исходников нет.
Нативный запуск, bootstrap/transport и общий HUD не добавляются.

Один trusted validator переиспользует общий XML parser/dependencies/Hud manifest,
проверяет fixed mapping, exact10 IDs/9 leaf plain Labels, initial root visible=false,
порядок двух definitions, четыре resource links и полную достижимость outputs.
Panel.visible разрешается только здесь через локальную allowlist; старые defaults
не расширяются. Bounded read_source/path/output/current-source policy существующая.

Единый handoff selector получает orders-timeline; existing экраны и outputs
сохраняются. Actual packaged XML/JS проверяются вместе в VM без Game API.
Сценарий не доказывает Source2/native UI или игровое выполнение приказов.
