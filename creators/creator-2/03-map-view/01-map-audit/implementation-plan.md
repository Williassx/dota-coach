# C2-03-01: план обследования файлов карты

> Исполнитель использует superpowers:executing-plans; пять критиков рассматривают
> результат read-only. Пользователь поручил автономное продолжение.

**Цель:** ограниченная инвентаризация файлов карты и свидетельства Steam build_id.
**Спецификация:** [design.md](design.md).
**Архитектура:** один read-only Python helper, существующий quoted_value импортируется;
карта не распаковывается, не копируется и не становится игровой геометрией.
**Стек:** Python 3.10+ stdlib, unittest; реальный Dota/Tools отдельно.

## Ограничения и внимание ревью

- Только отдел 2; C1/shared/foundation исходники не меняются.
- Входной root/предки и вложенные пути с symlink/reparse не обходятся.
- Все записи потребляют один бюджет; очень большие архивы не читаются целиком.
- Manifest другой установки не присваивает build_id обследуемой карте.
- Неполный/изменившийся файл и пустая loose-выборка не означают успешную геометрию.
- Отчёт не заменяет файлы пользователя и не записывается в установку/Steam.
