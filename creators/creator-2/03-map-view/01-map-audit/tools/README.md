# Обследование файлов карты

[Подпункт](../README.md) · [Дизайн](../design.md) · [Нативное продолжение](../notes/map-audit.md)

[inspect_map_workspace.py](inspect_map_workspace.py) принимает --dota-root с
фактически обнаруженным каталогом установки. --steam-library необязателен;
если указан, manifest должен относиться к тому же root. --help показывает лимиты.
Без --output выводится ASCII-safe JSON; --output создаёт новый UTF-8 report вне
установки/известной Steam library, не заменяет файлы и не создаёт parent.

CLI: 0 — завершённая инвентаризация, 1 — отсутствующий root/game path или неполное
обследование (JSON доступен), 2 — неверный ввод/отказ сохранения. Даже код 0
не подтверждает игровой патч, загруженную карту, геометрию или runtime.
