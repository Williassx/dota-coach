## Текущие факты

- Пользователь подтвердил Dota/Workshop Tools на Windows и клон D:\AI\dota2coach.
  Канал выполнения Windows к этому облачному чату не подключён.
- Концепт использует историческое изображение 7.40 из
  [описания визуального концепта](../../../../../docs/visual-concept.md).
  Оно не задаёт патч, координаты, обзор, высоты, проходимость или объекты runtime.
- Облачные тесты используют искусственные файлы, не VPK/карты Valve.
  Оригинальные ресурсы не копировались и не распаковывались.

## Как читать отчёт

Directory/game_directory_observed означают наблюдение каталогов. Locations указывает,
какие map/addon/archive roots существуют. Пустой произвольный каталог получает
root_unavailable; отсутствие loose карты при VPK не доказывает отсутствие карты.
Resources — кандидаты, а не активный шаблон или загруженная сцена.

Build_evidence.associated означает совпадение root с installdir AppState для appid570;
build_id — Steam идентификатор сборки. Он не является номером патча. Комментарии,
вложенные поля/дубликаты не могут подменить AppState; unsupported manifest даёт
invalid_manifest. Настоящая совместимость с Tools этим не подтверждается.

SHA complete означает полностью прочитанный малый файл с совпадающими stat/fstat
до/после. size_limit/total_limit оставляют только метаданные. changed/unreadable
не дают частичный SHA. Бюджет hash_bytes_read относится к bytes для SHA ресурсов;
manifest отдельно ограничен 65536 байт. entries_examined — посещения существующих
каталогов/записей, не уникальные файлы; truncated/issues исключают полный отчёт.

Actual_loaded_map/patch остаются null, runtime/geometry/compatibility — false.
Это не проверка лицензии; условия материалов описаны в
[юридическом плане](../../../../../docs/legal/plan.md).

## Действия локального исполнителя при появлении канала Windows

1. Прочитать C2-01-01 и получить реальные game_path/library из аудита среды.
2. Запустить helper с этими путями; отчёт сохранить новым *-local.json в reports,
   вне установки/Steam. Существующие reports/аддоны не заменять.
3. Записать build_id, кандидаты core/addon/source/compiled/archive, недоступные
   каталоги/лимиты и SHA только завершённых чтений.
4. В штатном Tools-шаблоне определить доступную map/scenario и подтвердить загрузку
   в той же версии клиента; выбрать её вместе с создателем 1.
5. Отдельно измерить мировые координаты, проходимость, высоты, обзор, башни/базы/
   лагеря и безопасную область камеры; не переносить геометрию из изображения.
6. Проверить совпадение карты/патча/сборки и сохранить нативный отчёт, не объявляя
   данные тренировочными наблюдениями до проверки допустимого обзора.

Это инструкция исполнителю, не поручение пользователю выполнять обычные команды.
