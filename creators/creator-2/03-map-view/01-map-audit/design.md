# C2-03-01: доказательства файлов карты

Пользователь поручил продолжать автономно до остановки. Следующий независимый
результат отдела 2 — ограниченный read-only аудит файлов, пригодный для запуска
на подтверждённом пути Windows. Нативная среда пока не подключена.

## Решение и границы

Изображение 7.40 не определяет текущую игровую карту. Копирование оригинальных
ресурсов и распаковка VPK не нужны для первого обследования. Выбран локальный
инвентаризатор файлов с отдельным доказательством build_id из Steam manifest.
Ресурсы не копируются, не изменяются, не компилируются; игровой патч и проходимость
не выводятся из имени файла, размера, build_id или SHA.

Единственный инструмент: tools/inspect_map_workspace.py, Python 3.10+ без пакетов.
inspect_maps(dota_root:Path, steam_library:Path|None=None, *, max_entries=2000,
max_files=80, max_hash_bytes=16777216, max_file_hash_bytes=4194304):dict.
CLI: --dota-root обязательно, --steam-library необязательно, --output необязательно;
лимиты соответствуют параметрам API. По умолчанию JSON в stdout, --output создаёт
новый файл вне установки/Steam и не заменяет существующий.
Лимиты строго int (не bool): entries 1..100000, files 1..1000,
hash_bytes 1..268435456, file_hash_bytes 1..67108864. stdout/новый report содержат
JSON даже при неполном обследовании. Status inventory_only даёт CLI 0,
partial_inventory/root_unavailable — 1, неверные аргументы/отказ output — 2.

## Инвентаризация

Обходятся content/dota/maps, game/dota/maps, content/dota_addons/*/maps,
game/dota_addons/*/maps. В game/dota фиксируются также *.vpk, без чтения структуры
архива. .vmap — source_candidate, .vmap_c — compiled_candidate;
.nav/.vnav/.vnav_c — navigation_candidate, без заявления о формате/проходимости.
Остальные файлы считаются в бюджете обхода, но не включаются в результаты.
Core/addon и content/game помечаются отдельно. Отсутствие loose-файлов не доказывает
отсутствие карты: она может быть упакована в VPK.

Один max_entries на весь обход (включая существующие каталоги/нерелевантные записи) и один
max_files для карты/архивов. Очередь итеративная. Существующие symlink/reparse
не обходятся, включая предков указанного root. Ошибки доступа и обрезание фиксируются;
неполная выборка не объявляется полным обследованием.
entries_examined считает посещения существующих каталогов и перечисленные записи,
а не число уникальных файлов; фиксированные проверки отсутствующих путей не входят.
Locations сохраняет наличие проверенных map/addon/archive roots. Нет game/dota —
game_directory_observed=false, missing_game_directory и root_unavailable, без
заявления, что произвольная существующая папка является установкой Dota.
FIFO/устройства/сокеты пропускаются до open; предварительный glob/list не применяется.

Для обычных малых файлов записываются путь, категория, размер, mtime_ns и SHA-256.
Большие файлы получают sha256=null с причиной ограничения; суммарное чтение
ограничено max_hash_bytes. Метаданные до/после чтения и идентичность открытого файла
сверяются; изменение даёт hash_status=changed, без частичного SHA. Это диагностическая
проверка, не атомарный снимок при враждебных изменениях файловой системы.

## Сборка и доказательства

Необязательная Steam library связывается с dota_root только если bounded manifest
steamapps/appmanifest_570.acf (до 65536 байт, без links/reparse) имеет appid=570,
корректный installdir внутри steamapps/common и тот же root. Quoted VDF value
разбирает существующая функция создателя 1; её реализация не копируется и не меняется.
Перед извлечением выполняется строгий ограниченный разбор AppState: // комментарии
игнорируются, вложенные поля не заменяют верхние, дубликаты/неподдерживаемый синтаксис
дают invalid_manifest; вложенность ограничена 64. C1 декодирует отдельные значения.
build_id сохраняется только при этой связи; Steam build_id не является номером патча.
buildid — непустая десятичная строка до 32 символов, без неё association не объявляется.
Импорт C1 выполняется с временным dont_write_bytecode, без записи __pycache__.
Output защищает dota_root и указанную Steam library; без --steam-library дополнительно
защищается библиотека, выводимая из формы steamapps/common/<install>. Прочие Steam
библиотеки не обнаруживаются. Symlink/reparse предков output запрещены, его parent
должен существовать. Исходные/неизвестные локальные пути не публикуются как fixtures.
При --output небезопасный root/Steam alias отвергается до записи. stdout JSON
с ASCII-экранированием поддерживает узкую кодировку Windows; файл отчёта — UTF-8.

schema_version=1; report содержит dota_root, directory_exists, resources, issues,
entries_examined, hash_bytes_read, truncated, build_evidence и status.
actual_loaded_map=null, patch=null, runtime_verified=false, geometry_verified=false,
compatibility_verified=false сохраняются во всех случаях. Отдельный concept_reference
помечает историческое изображение 7.40, не источник runtime-геометрии.

## Приёмка подготовленного инструмента

Реальные временные файловые деревья проверяют core/addon, source/compiled/archive,
SHA/сохранность данных, лимиты, отсутствие loose, привязку manifest, symlink/reparse,
ошибки/изменение файлов и отказ перезаписи отчёта. CLI выполняется в облаке только
на синтетическом/отсутствующем пути; это не обследование компьютера пользователя.
Фактическую карту, доступный Tools-шаблон, сборку, координаты, объекты, проходимость
и загрузку в Dota подтвердит отдельная нативная проверка и второй владелец.
