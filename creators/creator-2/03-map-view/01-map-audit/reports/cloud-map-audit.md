## Результат

Подготовлен ограниченный read-only helper для фактически обнаруженного dota_root.
Файлы core/addon/source/compiled/nav/VPK обозначаются кандидатами; archive contents
не читаются/не распаковываются. Ограничены обход, количество файлов, размер/общие
байты SHA и manifest. Существующие links/reparse/special files пропускаются.
Изменившийся файл не получает авторитетный SHA. Клиент/Tools и карта не запускаются.

Build_id связывается с установкой только через корректный AppState appid570;
это не патч. Actual_loaded_map/patch=null, runtime/geometry/compatibility=false
во всех результатах. Референс 7.40 из концепта отделён от runtime evidence.
Output создаётся новым файлом вне установки/известной Steam library; stdout
поддерживает CP1252 через ASCII-safe JSON, файл — UTF-8. C1 quoted_value импортирован
без изменения его исходников и записи bytecode; оригинальные ресурсы не добавлены.

## Пять направлений ревью

- Объём: соответствует отделу 2; нативная зависимость C2-01-01 и второй владелец сохранены.
- Архитектура: Steam alias позволял output попасть внутрь реальной library;
  комментарий appid подменял AppState. Оба воспроизведены RED и исправлены проверкой
  предков root/library до output и строгим ограниченным AppState parser.
  Повторное ревью подтвердило 30/30 и отсутствие связанных существенных замечаний.
- ИИ: файлы/SHA/build_id не выдаются за геометрию, обзор или обучающие наблюдения.
- Осуществимость: CP1252 stdout ломался на кириллице; воспроизведено/исправлено
  ASCII-экранированием stdout JSON. Повторно проверены stdout и UTF-8 output.
- UX: пустая папка получала код0/невнятное сообщение ошибок. Теперь отсутствие
  game/dota явно даёт root_unavailable/code1, locations отделяет loose от VPK,
  отсутствующие probes не расходуют entries_examined, ошибки называют аргумент/причину.
  Повторное ревью подтвердило исправления и 30/30.
