## Изменения

Созданы два ES5-модуля, XML/CSS отдельной панели, 27 VM-сценариев и документация.
Native gateway проверяет живого realhero команды локального участника перед
GameUI.MoveCameraToEntity. Адаптер принимает явно переданную цель и gateway;
без них кнопка отключена. Выбор и refresh не двигают камеру. Автоматического
bind, demo, игровых подписок, транспорта, команд юнитам и чтения origin нет.

Reference — community ModDota, закреплённый commit в [notes](../notes/camera.md).
Поддержка API в установленной Dota и stable id→entity ещё не подтверждены.
Requested означает возврат функции без исключения, положение камеры неизвестно.
Результат отдельно хранит исходную цель; одинаковые имена сравниваются по id/index.

Один адаптер владеет root до dispose. При bind/render failure обработчик удаляется;
повторный вход/getters и старые callbacks проверяются поколением и жизненным циклом.
Malformed stale result не закрывает новую цель. Исключение focus показывает
неподтверждённый запрос, а не прибытие камеры.

## Ревью и ограничения

Пять направлений рассматривают изменения read-only; критики не заменяют владельца:

- Объём: зависимости/общий контракт/сервер сохранены; native identity и hittest открыты.
- Архитектура: до кода уточнены строгие native значения и защита повторного входа;
  финальный независимый прогон 27/27, XML/resources корректны, существенных дефектов нет.
- ИИ: нет приказов/позиций/изменения AI/MANUAL; принадлежность команде не доказывает identity.
- Осуществимость: самостоятельно пройдены 26 сценариев до UX-исправления;
  сверены API, node syntax, XML/resources/labels и CSS, native proof отсутствует.
- UX: исправлены одинаковые имена/прежняя цель и «свой герой» → «герой команды».
  Повторная проверка воспроизведения подтвердила обе поправки.

Команда сохранена только в start_skill; readback подтвердил сохранение остальных
полей настройки. requires_publish=true: активация требует рассмотрения, сохранения
и публикации в настройках среды. Install_script, зависимости, сеть, секреты,
репозитории и runtime-переменные не менялись.

Не выполнены: native focus/arrival, identity mapping, custom heroes, общий HUD,
камера/bounds/hittest/масштабирование, обозначения/обзор и второй владелец.
Приёмка всего C2-03-02 не закрыта. Существующие UI, сервер и foundation manifest
не менялись; новые исходники остаются в библиотеке создателя 2.
