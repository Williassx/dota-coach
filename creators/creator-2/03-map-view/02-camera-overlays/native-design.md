# C2-03-02: ограниченная native TEST-проверка

Ведущий: роль 76, создатель 2. Самостоятельный результат помощника 107/114 —
сборщик и проверки целостности. Root владеет driver, отчётом и общими документами.
Применяются brainstorming/writing-plans; пользователь разрешил продолжение плана.

Использовать существующие camera_panel/camera_native без изменений, в производной
TEST-сцене fixed HUD13. Канонические 13 исходников и политика упаковки сохраняются.
Панель находится в CoachCamera. TEST-драйвер явно bind/dispose, не bootstrap продукта.
Локальный герой определяется через проверенные в runtime API Players/Game; id и имя
виртуального игрока тестовые. Это не stable identity mapping и не C1-контракт.

Критерии: без цели кнопка отключена; setTarget/refresh не вызывают native focus;
явная программная активация кнопки вызывает ровно один настоящий gateway.focus и
отображает requested; отрицательный индекс native gateway отклоняет; dispose/rebind
закрывает прежний API до чтения DTO. Программная активация не physical input/hittest.

TEST-only наблюдение GetCameraLookAtPosition и координат своего проверенного живого
realhero допускается после native guard. Не читаются чужие/скрытые координаты.
Дистанция камеры до героя — измерение текущего положения; даже нулевая дистанция
не доказывает, что запрос вызвал прибытие, если камера уже там. Production gateway
по-прежнему не читает координаты и не утверждает прибытие. Не менять положение
камеры другими API, не добавлять слежение, приказы или маркеры.

Приёмка ограничена template_map и фактическим размером кадра. Второй создатель,
геометрия настоящей карты, версия/обзор, масштабирование и авторизация открыты.
Новый addon создаётся только при отсутствии собственных каталогов и чужого клиента;
завершение через quit относится только к сохранённому собственному PID.
