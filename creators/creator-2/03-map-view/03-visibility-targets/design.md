# C2-03-03: просмотр допустимой цели

Пользователь поручил автономное продолжение до остановки. Создаём небольшой
компонент просмотра выбранной цели для будущего клика карты. Источник наблюдений
C1-03-01 не реализован; готовим частную UI-проекцию, не общий сетевой контракт.

## Выбранный объём

Native чтение произвольных сущностей могло бы обойти будущий разрешённый обзор.
Поэтому компонент получает уже отфильтрованные наблюдения от явно подключённого
переходника; сам не перечисляет сущности, не читает позиции и не отправляет приказ.
Панель показывает выбранную видимую цель либо объясняет отсутствие допустимого
выбора. Скрытая/исчезнувшая цель сразу теряет подпись и entityIndex в UI.

Сравниваем три направления: native polling отложен до проверки версии/авторизации;
полная карта отложена до геометрии; используем малую UI-проекцию без координат.
Достоверность видимости/identity/action eligibility остаётся обязанностью сервера.
Frontend filtering не является границей безопасности, клиентские заявления не дают прав.

## Частная проекция

Snapshot ровно {revision,targets}; revision int0..9007199254740991, targets array<=32.
В пределах одного экземпляра revision строго растёт; новый матч требует новый model.
Сначала читается revision: old/duplicate не читает targets. Новая допустимая
revision потребляется даже при malformed body; high-water сохраняется после
invalid/expiry. Исправленная проекция требует следующую revision.
Все id уникальны, непустая строка<=64 без пробельных краёв.

- Видимая запись ровно {id,visibility:"visible",label,team,kind,alive,entityIndex}.
  label непустая непробельная строка<=64, team ally|enemy, kind hero|creep,
  alive boolean, index int0..2147483647. Координат/способностей/характера нет.
- Hidden/gone/unknown запись ровно {id,visibility}; другие поля отвергаются без
  чтения значений label/entityIndex. Её id служит только инвалидированию выбора.
  Источник передаёт такие id только для ранее разрешённого знания, не перечисляет
  новые скрытые объекты. Gone означает выпадение из наблюдения, не подтверждённую
  скрытую смерть. При одинаковом разрешённом наблюдении изменение скрытых объектов
  не должно менять UI-проекцию: это открытая приёмка переходника C1-03-01.

Полный snapshot заменяет предыдущий: отсутствие id равносильно исчезновению.
Локальная freshness отсчитывается от приёма, а не server timestamp; обновление
старой/равной revision не продлевает срок. Это ограничение UI, не гарантия сетевой
свежести. Native reconnect/heartbeat/epoch/авторизация ещё не реализованы.

## Model и панель

DotaCoachTargets.create({now,maxAgeMs}) → update(snapshot):bool, select(id|null):bool,
view():copy, dispose():void, isDisposed():bool. now — явно переданная функция
монотонного времени в миллисекундах; maxAgeMs int1..60000. Без допустимых options
create отклоняется. Нет default data/native clock/demo.

View содержит status, message, target. target либо null, либо независимая копия
видимых полей выбранного объекта без visibility. Status: empty (не выбрано), ready
(видно/жив), dead, unavailable (hidden/gone/unknown/отсутствует), stale, invalid,
disposed. Ни один статус не означает, что сервер разрешит/выполнит приказ.
При смене данных hidden/gone/unknown/removal/death срок/копии обновляются атомарно;
потеря видимости снимает выбор. Повторное появление не выбирает цель автоматически.
Причина unavailable сохраняется отдельно от снятого выбора до явного нового
select/null. Для hidden — «Цель больше не видна», gone/removal — «Цель больше не
наблюдается», unknown — «Доступность цели неизвестна»; прежние имя/index отсутствуют.
Expiry/clock failure возвращают target=null и убирают подписи немедленно.
Invalid full snapshot очищает view, не оставляет смешанные или прежние подписи.
Old/duplicate revision сохраняет текущий snapshot без продления срока и чтения тела.
Expiry age>=maxAgeMs проверяется синхронно в update/select/view, watcher только
обновляет отображение. now возвращает конечное неотрицательное число.

DotaCoachTargetPanels.bind(root,options) → update,select,refresh,dispose,isDisposed.
Панель TargetTitle/TargetDetails/TargetStatus, все labels plain text. Показывает
свой/вражеский герой/крип и жив/мёртв без утверждения доступной атаки или деная.
Она не содержит actionable controls. Интегратор выбирает id через select.
Watcher $.Schedule каждые0.1с обновляет expiry; dispose отменяет watcher и владение
root. Один адаптер на root, rollback partial bind/render/schedule failure.
Закрытие очищает/скрывает старые подписи до освобождения root; новое связывание
может снова показать поля. Между записями проверяется поколение рендеринга.
Повторный вход в watcher сохраняет одну запланированную проверку expiry.

## Жизненный цикл и отказы

Чтение входов/now может вызвать повторный вход. Closed/generation проверяются после
всех пользовательских чтений; старая операция не восстанавливает закрытый model и
не перезаписывает более новое update/select. Массив ограничен до и после копирования.
Сбой/обратный ход/нечисловое время убирает выбранные данные; актуальная новая revision
нужна для восстановления. После expiry данные не восстанавливаются старым snapshot.
Panel перед paint проверяет актуальный root; старый watcher после dispose не рисует.

## Приёмка исходников

Node VM исполняет реальные ES5: ally/enemy hero/creep, dead, hidden/gone/unknown/
removed, duplicate/stale revisions, expiry boundary, invalid fields/coords/bounds,
копии/plain text, clock error, getter reentrancy, panel lifecycle/scheduling.
GameEvents/Entities/origin/orders/mouse отсутствуют и в тестах запрещены.
XML/CSS/resources/IDs проверяются отдельно. Native карта/сервер/мышь/hittest,
identity/видимость и второй владелец остаются открытыми.
