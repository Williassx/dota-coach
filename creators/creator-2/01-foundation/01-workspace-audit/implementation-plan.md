# C2-01-01: план обследования Panorama

**Цель:** подготовить повторяемую локальную инвентаризацию для создателя 2.
**Спецификация:** [design.md](design.md). Критик осуществимости рассмотрел её;
его требования по NTFS reparse points и суммарному бюджету внесены до реализации.
Это техническая проверка проекта, не план нового игрового поведения.
**Технологии:** Python 3.9+, unittest, Git; без установки сторонних пакетов.

## 1. Помощник и проверки

Файлы: `tools/inspect_ui_workspace.py`, `tests/test_inspect_ui_workspace.py`.
Интерфейсы: `inspect_panorama(dota_root: Path, max_entries=2000, max_files=80) → dict`,
`build_report(repository: Path, steam_roots: list, dota_roots: list) → dict`.
CLI: `--repository`, повторяемые `--steam-root` и `--dota-root`, `--output`.

1. Создать файловые проверки, убедиться в RED без помощника.
2. Импортировать C1 обследователь по его единственному пути относительно исходника;
   параметр repository не выбирает исполняемый Python-модуль.
3. Ограничить потоковый обход addon/Panorama суммарным бюджетом для двух деревьев.
   Проверять lstat/reparse и разрешённую границу до перечисления каждого каталога.
   Обход итеративный; регрессионный тест подтверждает независимость от стека Python.
4. Выдавать относительные примеры XML/JS/CSS и VXML_C/VJS_C/VCSS_C, ошибки и
   признак усечения; не читать содержимое ресурсов.
5. Проверить, что отсутствующая установка не выдана за готовность, ссылки не
   обходятся, чужие файлы и существующие отчёты сохраняются. Подтвердить GREEN:

```sh
python3 -m unittest discover -s creators/creator-2/01-foundation/01-workspace-audit/tests -v
python3 -m unittest discover -s creators/creator-1/01-foundation/01-environment-audit/tests -v
python3 creators/creator-2/01-foundation/01-workspace-audit/tools/inspect_ui_workspace.py
```

## 2. Локальная Windows

Инструкции: [windows-start.md](notes/windows-start.md). Данные пользователя не
переписывать. Сохранить локальный JSON, записать проверенные пути и выбранный
способ открытия шаблона в [workspace-audit.md](notes/workspace-audit.md).
Реальный NTFS junction и запуск Tools проверить на Windows отдельно от имитации
флага reparse в облачных тестах. После рассмотрения создателем 1 закрыть C2-01-01.

## 3. Передача следующей части

Полученные пути и версия — входы C2-01-02. Облачный успешный запуск помощника не
снимает этот локальный вход. Обработчик ответа остаётся в области создателя 1.
Настоящую сборку/установку сначала описать по найденному шаблону; не создавать
копии ресурсов и неподтверждённые команды запуска.
