# Продолжение создателя 2 на Windows

Клон `D:\AI\dota2coach` уже есть по подтверждению пользователя. Повторно клонировать
его не нужно. Облачная задача не получает доступ к этому диску от одного открытия
Codex: следующие действия выполняются в локальной задаче этого проекта.

## Задание локальному Codex

Скопируйте в новую локальную задачу проекта:

> Я создатель 2. Продолжи C2-01-01 в D:\AI\dota2coach. Прочитай AGENTS.md,
> creators/creator-2/AGENTS.md и материалы creators/creator-2/01-foundation.
> Проверь незакоммиченные изменения и получи актуальный origin/main, сохранив мои
> файлы; обновление рабочей ветки допускается только fast-forward. Не удаляй,
> не сбрасывай и не прячь изменения автоматически. Выполни диагностический
> помощник C2, запиши реальные пути Steam/Dota/content/game/Panorama, исследуй
> доступный локальный шаблон и способ компиляции. Сохрани только краткое резюме
> без лишних персональных путей в notes/workspace-audit.md. JSON оставь локально.
> Затем уточни план C2-01-02 по этим фактам и подготовь UI-часть. Серверный ping
> принадлежит создателю 1; чужие файлы и существующие аддоны не заменяй.
> Проверку Lua-ответа проведи совместно после появления обработчика; пять
> критиков рассматривают результат, но не заменяют второго владельца.

## Ручной запуск диагностики

Откройте PowerShell в этом проекте. Нужен установленный Python 3.9+;
в облаке он есть, наличие на Windows ещё не проверено. Если команда `py` отсутствует,
локальный Codex проверяет доступный `python` и его версию; файлы Steam можно
обследовать вручную до подготовки интерпретатора.

```powershell
Set-Location 'D:\AI\dota2coach'
py -3 creators/creator-2/01-foundation/01-workspace-audit/tools/inspect_ui_workspace.py
```

Сохранение нового отчёта (каталог reports уже предусмотрен):

```powershell
$uiReport = 'creators/creator-2/01-foundation/01-workspace-audit/reports/windows-' + (Get-Date -Format 'yyyyMMdd-HHmmss') + '-local.json'
py -3 creators/creator-2/01-foundation/01-workspace-audit/tools/inspect_ui_workspace.py --output $uiReport
```

Если Steam не обнаружен, добавьте `--steam-root` с его фактическим путём.
Если известно расположение Dota, добавьте `--dota-root` с её фактическим корнем
(родителем game/content). Пути Steam не заменяйте догадками.

Код выхода 0 означает, что инвентаризация составлена; он не означает готовность
Tools. `runtime_verified: false` остаётся таким до отдельной проверки клиента.
`truncated: true` означает частичный список; ссылки/reparse points пропущены.
Существующий отчёт не переписывается. Не публикуйте полный локальный JSON.
