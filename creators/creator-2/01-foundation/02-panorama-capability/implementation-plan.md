# C2-01-02: план нативной проверки

**Статус:** локальный аудит, UI/карта и видимость панели в обычном клиенте и Tools
подтверждены; ввод/lifecycle/C1 остаются открытыми. **Спецификация:** [design.md](design.md).
**Источник API:** [зафиксированные материалы](notes/panorama-probe.md).
**Владелец:** создатель 2 — XML/CSS/JS; создатель 1 — ранний Lua ping в C1-01-02.

## 1. Подготовить исходники независимо от Windows

Это уточнение по поручению пользователя продолжать без его ручного участия.
Ранее рассмотренная панель сохраняет тот же объём. Границу установки/приёмки не
снимать: исходники и облачные поведенческие проверки можно делать сейчас.
Критики рассматривают уточнение до реализации.

Файлы поведения: `src/panorama/scripts/custom_game/coach_probe_state.js` и
`coach_probe.js`. Состояние экспортируется в общий контекст Panorama через
переменную DotaCoachProbe; CommonJS/npm в игровом коде не используются.
Node.js 18+ со встроенными node:test/vm используется только как облачный проверяющий.
В текущей среде подтверждён Node.js 24.19.0; сторонних пакетов нет.

Создать проверки RED до исходников, затем реализовать:

- Один активный запрос, подписка до отправки, уникальные ID между перезагрузками.
- Коррелированный ok/rejected: отмена таймера, сохранение результата, повторный запрос.
- Тайм-аут, поздний ответ, чужой ID, неизвестная версия/статус, ошибка транспорта.
- Освобождение при перезагрузке/закрытии, один обработчик и отмена всех таймеров.
- Привязка точных игровых JS к модельным GameEvents/Panel/Schedule; XML-пути
  проверить парсером. Это модель движка, не нативная приёмка.

Команда из корня: `node --test creators/creator-2/01-foundation/02-panorama-capability/tests/*.test.cjs`.

## 2. Завершить входы Windows

11 октября выполнены локальный аудит и компиляция пяти UI-ресурсов в отдельном
`dota_coach_c2_probe_20261011`. Конкретные root, команды и ограничения:
[Windows foundation](../01-workspace-audit/reports/windows-foundation-2026-10-11.md).
В manifest штатного workshop_testbed найден CustomUIElement type=Hud.
В продолжении того же дня template_map успешно скомпилирована без `-novpk`:
этот флаг исключал базовые VPK из GAME search paths установленной версии.
Локальный игровой клиент подтвердил panel_ready/request_sent. Видимость панели
и кнопки подтверждена скриншотом1280×720; hittest/timeout/reload открыты после DXGI-падения клиента;
в продолжении подтверждён отдельный Tools runtime и его HUD. Native справка
подтвердила используемые bindings событий, таймеров и панели. Захват через
Windows Computer Use не дал кадра, а UI Automation — элементов внутри сцены;
нельзя подменять проверку клика вызовом fake sender. C1 transport открыт.
Использовать команду карты
без `-novpk` из Windows-отчёта, не выдавать compile за нативную приёмку.

Реальная установка, шаблон, manifest, команды сборки и отдельная сцена для C2
закреплены в Windows-отчёте выше. C1 независимо завершает свой аудит и bootstrap;
готовая C2 сцена не подтверждает серверный контракт или полномочия отправителя.

## 5. Проверить поведение в Dota

1. Загрузить отдельную сцену, убедиться в отсутствии XML/JS ошибок.
2. Нажать кнопку: один запрос, тот же ID в серверном журнале, адресный ответ,
   видимое подтверждение. Зафиксировать сборку и оба журнала без SteamID.
3. Проверить отсутствие обработчика: тайм-аут и новая попытка с другим ID.
4. Проверить устаревший ID/другую версию/повторную загрузку: нет ложного успеха
   и дублирования подписок. Если доступен второй клиент, проверить адресность;
   без него проверка адресности для двух клиентов остаётся непроведённой.
   Проверить отказ и успех: таймер отменён, итог не меняется дубликатом или старым
   таймером, повторная проверка разрешена; отказ сохраняется дольше тайм-аута.
5. Проверить штатный ввод карты вне панели и отсутствие изменений героя.
6. Записать результат каждого сценария в notes/panorama-probe.md; передать
   создателю 1, затем обновить README. При ошибке сохранить её и исправить причину.

Без рабочего канала нативного ввода и настоящего Lua-обработчика полная
приёмка перечисленных сценариев остаётся открытой.
