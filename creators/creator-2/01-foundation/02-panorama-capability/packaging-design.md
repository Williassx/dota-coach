# C2-01-02: отдельный пакет исходников панели

Продолжение автономной работы создателя 2. Цель — воспроизводимый пакет пяти
ресурсов Panorama для последующей локальной интеграции. Это разрешённая ранняя
упаковка первой сцены по [общим правилам](../../../shared/INTEGRATION.md).
Серверный код, установка и компиляция Source 2 в эту задачу не входят.

## Выбор

Ручное копирование трудно проверять и создаёт редактируемые дубликаты. Полная
сборка аддона требует ещё не обследованных Tools и серверной части. Поэтому
создаётся небольшой сборщик исходных UI-ресурсов с явным manifest.

Единственные исходники остаются в src/panorama. JSON manifest сопоставляет
относительный путь исходника в репозитории с относительным путём пакета
`content/panorama/...`. Это структура подготовленного пакета, не установленный
Windows-путь. Сборщик не объявляет её подтверждённой установочной схемой.

## Поведение

Python 3.9+, стандартная библиотека. Входы: репозиторий, manifest и новый выходной
каталог внутри `build/dota_coach/`. По умолчанию выбирается уникальный дочерний
каталог. Готовый/частичный существующий каталог не заменяется и не очищается.
Сборщик не запускает команды, сеть или Dota и не читает другие отделы.

До создания результата проверяются все записи: источник только в src/panorama
этого подпункта; назначение только в content/panorama; XML/JS/CSS; отсутствие
абсолютных/выходящих путей, symlink/NTFS reparse points, дублирующих и конфликтующих
назначений, включая различие регистра на Windows. Пути manifest используют `/`;
запрещены обратные слеши, двоеточия/drive/UNC, Windows device names, управляющие
символы и сегменты с завершающей точкой/пробелом. Проверяются также все существующие
выходные предки: build, dota_coach и промежуточные каталоги до нового результата.
Обход источников — только
пять явно перечисленных файлов. Максимум 100 записей, каждый ресурс до 1 MiB.

Байты читаются до записи. Пакет создаётся в новом каталоге, ресурсы — эксклюзивно.
Последним создаётся bundle-report.json: относительные исходник/назначение, размер,
SHA-256 и явные признаки source2_compiled=false, runtime_verified=false. Отсутствие
валидного отчёта означает незавершённую упаковку; при проверке требуются также
совпадающие хеши ресурсов. Ошибка записи не выдаётся за успех;
частичный каталог сохраняется, чтобы не удалять возможные чужие изменения.

## Приёмка

- Пять файлов пакета совпадают с источниками по байтам и SHA-256.
- XML-ссылки разрешаются внутри пакетного content/panorama, порядок JS сохранён.
- Настоящие JS из пакета проходят существующие поведенческие проверки через
  явный путь ресурсного корня; источники продолжают проверяться по умолчанию.
- Некорректный manifest не создаёт выход; существующие каталоги и файлы сохраняются.
- Переходы за границы/ссылки и конфликты регистра отклоняются до записи.
- Пакет не считается скомпилированным или запускаемым аддоном; Windows/Lua всё ещё нужны.

Рассмотрение пяти критиков и другого владельца различаются. Нативный подпункт
не закрывается по результату упаковки. Инструкция подключения остаётся для агента,
рутинные команды пользователю не передаются.
