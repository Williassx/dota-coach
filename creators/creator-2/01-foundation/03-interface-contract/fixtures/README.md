# Искусственные примеры ping

[Подпункт](../README.md) · [Предложение полей](../notes/ui-contract-input.md).
Три JSON — запрос, успешный ответ и отказ неизвестной версии.
Одинаковый ID в запросе/успехе означает корреляцию; ID отказа относится к другой попытке.
Это предложения, не доказательство обмена в Dota.
