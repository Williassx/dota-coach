# Генератор графика

[Родитель](../README.md) · [update_progress.py](update_progress.py).

Читает чек-листы, строит таблицу и диаграмму с фиксированной шкалой 0–100%.
Выводы записываются в корень библиотеки создателя 2. SVG строится Matplotlib;
проверка выполняется командой `--check`. Временный кэш графики хранится в /tmp.
