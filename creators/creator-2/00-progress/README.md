# Прогресс создателя 2

[Библиотека](../README.md) · [График и таблица](../PROGRESS.md) · [Инструменты](tools/README.md).

Процент раздела = число `[x]` / число всех пунктов в `## Действия` README его
трёх подпунктов × 100. Общий процент считается по сумме пунктов, а не по среднему
разделов. Это доля отмеченных действий, не оценка времени или готовности игры.
Нативные проверки и второй владелец отмечаются только после фактической приёмки.
Дополнение чек-листа меняет знаменатель; исходники сами по себе не закрывают пункт.

Единственный источник — чек-листы подпунктов. PROGRESS.md, progress.svg и progress.json
генерируются; их вручную не редактировать. В конце каждой задачи после обновления
чек-листа выполнить из корня репозитория:

```bash
python3 creators/creator-2/00-progress/tools/update_progress.py
python3 creators/creator-2/00-progress/tools/update_progress.py --check
```

`--check` проверяет совпадение графика/таблицы/данных с текущими чек-листами, без записи.
Генератор требует Python 3 и Matplotlib (в этой облачной среде установлен 3.10.8).
Он читает ровно разделы 01–12 и три подпункта каждого, не сканирует планы/архивные отчёты.
При отсутствии раздела/подпункта/чек-листа завершает работу с ошибкой, не подставляет 0.
