# План native text preview

[Дизайн](native-design.md). Выполняется автономно в текущем checkout.

1. RED→GREEN проверок fixture builder: сохранение canonical bytes/graph,
   deterministic assets, refusal existing/escape/missing driver/changed mapping/
   executable manifest. Fixed kind не расширять.
2. Создать test-only manifest/driver, public API assertions и TEST designation.
3. Свежая сборка; только absent addon dirs, hash check installed sources;
   compile manifest/template map. Не использовать -novpk.
4. Own Dota launch на1280×720; VConsole свежий marker; штатный Axe test hero.
   Снять screenshot после каждой native phase, конвертировать и осмотреть.
   Это API-driven scene, не физический input acceptance.
5. Quit/check owned PID; targeted tests + required full source runner, честно
   сохранить platform failures. Report/indices/resume/journal/урок по evidence.
6. Один final technical critic; проверки docs/graph/diff, обычная публикация.
