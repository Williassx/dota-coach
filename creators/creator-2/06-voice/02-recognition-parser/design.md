# Ограниченный разбор текста тренера

[Подпункт](README.md). Решение исполнителя в рамках автономной работы пользователя.

Цель: первый независимый C2 результат для голоса — уже распознанная финальная фраза
превращается в локальное предложение. Микрофон, ASR и общий серверный контракт ещё
не проверены; модуль не отправляет команды, не меняет режим и не обещает эффект.
Автор C2; реализация/тесты только здесь. Используется единственный DotaCoachRoster
из C2-02-01 для валидации карточек и availableForOrders, без копии его правил.

API DotaCoachVoiceText.create(): update({revision,players}), ingest(event), view(),
vocabulary(), dispose(). Snapshot players — существующие семь полей карточки,
revision — локальная монотонная safe integer. Это локальная оболочка, не новая
версия общего контракта. update атомарен, до пяти карточек; отказ не заменяет
последний валидный snapshot. Freshness/полномочия обязан проверять будущий C1 adapter.

Event: {utteranceId,text,rosterRevision,final}. Нефинальный event даёт interim без
предложения/истории. Финальный требует текущую revision. Один ID рассматривается
один раз, включая неизвестный текст/устаревшую ревизию; исправление требует нового
ID. До 128 финальных ID за жизнь экземпляра; при заполнении отказ history_full,
без вытеснения старых ID. Это локальная защита дублей, не server exactly-once.
Сохраняются только ID, не записи речи/текст; пересоздание не переносит историю.

Грамматика: «адресат, действие», одно предложение. Адресат — точное нормализованное
имя playerName, «керри/мидер/оффлейнер/четвёрка/пятёрка» либо «все/команда».
Позиции 1..5 соответствуют existing role. Группа — все свои карточки; недоступность
любой отклоняет весь proposal. Несколько совпадений или интерпретаций не выбирают
случайного игрока. Герой, выбранная мышью карточка и скрытые враги не используются.

Четыре local action: farm («фарми/фармите»), retreat («отступай/отступайте»),
regroup («соберись/соберитесь»), hold («держи позицию/держите позицию»).
Никаких координат/целей по умолчанию: атака, покупка и сложные фразы пока unknown_action.
Ё→е, нижний регистр, пробелы и запятая; конечные .!? убираются. Остальные символы
вне букв RU/ASCII, цифр, пробела, дефиса/underscore отклоняются. Нет транслитерации,
fuzzy matching/угадывания. «не/нет», «и/или/потом/затем» отклоняются явно.

Plain DTO копируется из own data descriptors, без getters; bounded массив до5.
Busy guard запрещает вложенные update/ingest; dispose во время Proxy trap остаётся
окончательным. Внешние DTO/result mutation не меняют private snapshot/history.
Proposal: utteranceId, rosterRevision, action, recipientIds, addressKind; это
намерение для будущего рассмотренного adapter. В нём нет PlayerID, epoch, lease,
целей мира или серверного разрешения. Native API/сеть/таймеры не вызываются.
