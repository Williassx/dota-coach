# Инструкции отдела создателя 2

Прочитайте корневой AGENTS.md, [PLAN.md](PLAN.md), README выбранного раздела и подпункта.
Начинайте исследование, заметки, исходники и проверки в соответствующей папке этой библиотеки.

- Изменяйте файлы отдела 2; для чужого отдела передайте конкретную задачу его владельцу.
- [Общие контракты](../shared/contracts/README.md) изменяет один назначенный автор после рассмотрения обоими.
- Другой создатель проверяет каждое изменение; у обоих одинаковые права на объединение после проверок.
- Статус подпункта обновляйте по фактам; неподключённая Windows не считается проверенной.
- После каждой задачи документируйте действия отдельно в [00-action-log](00-action-log/README.md):
  поручение, изменённые файлы, проверки и результаты, commit/отчёт, незавершённые шаги.
  Журнал дополняйте за дату UTC; технические отчёты и статусы оставляйте в своих подпунктах.
- Новые каталоги именуйте `NN-purpose`, снабжайте README и добавляйте ссылки в родительский индекс.
- Сохраняйте один источник каждого модуля; не копируйте реализацию в другую библиотеку.
- Автоматическую сборку/установку в Tools определяйте после проверки реальных путей. Не заменяйте существующие аддоны и пользовательские изменения.
