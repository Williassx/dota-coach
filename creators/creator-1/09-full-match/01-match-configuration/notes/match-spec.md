# C1-09-01: спецификация первой полной версии (предложение создателя 1)

Дата: 13 октября 2026. Совместное рассмотрение со вторым создателем открыто.

## Версия запуска

- `launchVersion`: единая строка версии (карта + правила + ограниченный
  контент); все акторы, карта и правила принадлежат ей.
- `map`: `template_map` (единственная подтверждённая сборкой карта);
  штатная карта — после аудита C2-03-01.
- `patch`: не установлен (пропуск из C1-05-01) — поле обязательно,
  значение `null` блокирует старт смешанного состава.
- `rosters`: две пятёрки по правилам C1-07-01 (валидатор обязателен).
- `content`: ограниченный набор C1-08-02 (гейт без патча блокирует).

## Реализация

Валидатор привязки — `src/match_config.py` (`bind_version`);
проверки — `tests/test_match_config.py` (5/5 OK).

## Сопоставление с критерием

Критерий «все акторы, карта и правила принадлежат согласованному запуску
и патчу» на pure-уровне покрыт обязательными полями и блокировкой при
`patch: null`. Не проведено: старт смешанного состава 5×5 в движке,
совместное рассмотрение, передача создателю 2.
