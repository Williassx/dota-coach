## Результат и приёмка

Пауза не расходует время вмешательства; записи позволяют восстановить причины переходов.

## Подготовленная pure-часть (без native clock, 13 октября 2026)

- `src/scripts/vscripts/event_log.lua` — построитель записей `seq/clock/type/actorRef/payload`; clock передаёт вызывающий код явно (игровое время — после нативного факта); свежий экземпляр на активацию, seq строго растёт.
- `tests/test_event_log_sources.py` — 4 статические проверки: отсутствие нативных вызовов времени/паузы в коде, форма записи, свежий экземпляр без глобалов, отказ bad-type/bad-actor.
- Источник игрового времени и поведение паузы остаются предметом нативного эксперимента; приёмка «пауза не расходует время» не заявляется.
