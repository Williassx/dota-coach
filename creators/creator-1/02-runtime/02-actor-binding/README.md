## Результат и приёмка

Приказы старой привязки не воздействуют на нового героя; чужое назначение отклоняется.

## Подготовленная pure-часть (без native, 13 октября 2026)

- `src/scripts/vscripts/actor_binding.lua` — чистая тройка «проектный id ↔ seat ↔ entity» с ревизиями; `Accepts` отклоняет stale entity/revision; `Unbind` для замены/смерти/переподключения (очистка перед новой привязкой).
- `tests/test_actor_binding_sources.py` — 5 статических проверок: отсутствие нативных вызовов владения в коде, тройка+ревизии, отклонение stale, запрет глобального кеша, отсутствие таймеров.
- Нативные вопросы (seat-герой r9/r10, владение, авто-аггро) остаются открытыми; приёмка критерия не заявляется.
