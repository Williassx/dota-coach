**Спецификация:** [design.md](design.md). **Факты:** [notes/lifecycle.md](notes/lifecycle.md).
**Технологии:** Lua vscripts; Python unittest; установка — отдельной командой (как в C1-01-02).

| Файл | Назначение |

| `src/addoninfo.txt` | maps=template_map, IsPlayable=1 |

| `tools/lifecycle-command.ps1` | Install/Launch/Quit по проверенному рецепту |

## Интерфейс скрипта (дизайн — договор)

- Глобальный guard: `_G.D1C201_ACTIVE`. Двойной активация лог `D1C201
  double-activate ignored`, второй режим не создаётся.
- Печать фаз: `D1C201 phase <STATE>` — один раз на фазу (SetThink основной
  пульс + отслеживания уникальности состояний в таблице объекта).
- Остановка: `D1C201 stop` + `return nil` при `DOTA_GAMERULES_STATE_POST_GAME`.
- Имя Think: `D1C201Think`, интервал 1 с (факт шаблона).

## Статические проверки (до нативного прогона)

1. Guard-флаг присутствует, двойная активация не создаёт второй Think
   (один вызов `SetThink` в файле).
2. Post-лог остановки и `return nil` присутствуют.
3. Ни один юнит-трекер не сохраняется глобально (`_G.` только D1C201_ACTIVE).
4. User-Human передача управления не вызывается (владение — вне этого подпункта).

## Нативная последовательность (не считать успехом до фактической)

1. `lifecycle-command.ps1 -Mode Install` — свежая папка аддона + компиляция карты.
2. `-Mode Launch -Run r6`; ожидание `GAME_IN_PROGRESS`(~4.5 мин). Фазы лога и
   однократность записей проверяются в отчёте; `-Mode Quit`.
3. `-Mode Launch -Run r7` — второй последовательный запуск; в его логе не должно
   быть записей от r6 («старых» фаз/юнитов), количество `phase INIT` и пр. —
   по одному на фазу; stop-лог по одному. `-Mode Quit`.
4. Отчёт в `reports/`, README обновление.
