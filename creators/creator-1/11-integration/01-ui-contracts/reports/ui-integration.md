# C1-11-01: сервер и Panorama (статус и сопоставление)

Дата: 13 октября 2026.

## Статус

Единой версии общего контракта пока нет (предложение C1-01-03 ждёт
рассмотрения C2-01-03) — сверка реализации с ней открыта. Закрыта
проверка поведения по предложению: устаревшие снимки, повторы и чужой
отправитель судятся правилом (`stale-snapshot` / `repeat` /
`foreign-sender`); старый ответ прежний режим не возвращает.
Проверки — `tests/test_ui_contracts.py` (3/3 OK).

## Сопоставление с критерием

Критерий «интерфейс отражает сервер» требует Panorama-половины —
не проведён. Закрыто правило серверной стороны. Не проведено: единая
версия контракта, показ принятия и реального результата, приёмка
вторым создателем.
