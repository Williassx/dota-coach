# Исследовательский probe телеметрии

[Подпункт](../../README.md). Пользователь 14 октября 2026 поручил следующий шаг после разбора: получить телеметрию из `.dem` и сопоставить её с нативными кадрами.

Это временный локальный эксперимент, не игровой импортёр и не персональная модель. `TelemetryProbe.java` — один локальный источник probe, исключённый из Git; зависимости, классы, raw dumps и JSONL находятся в ignored `build/dota_coach/replay-9042986015/telemetry-spike`. Исходный реплей не меняется. Исследовательский результат и pin/хэши сохраняются отдельно в notes/reports.

Порядок: (1) Clarity5.0.1/protobuf7.1, JDK21, local-only Maven/deps; (2) полный проход реплея, обнаружение настоящих полей GameRules/PlayerResource/Storm; (3) clock/account→assignedhero/handle+serial/illusion; (4) состояния в известных эпизодах; (5) независимая сверка. Missing field остаётся null; spectator state не является допустимым наблюдением ИИ.

Критерий probe: реплей прочитан до конца; actor и часы имеют явное происхождение; числовые состояния найдены в реальных netprops, raw control сохранён без выдуманного enum; расхождения с HUD не скрыты. До точного выравнивания времени HP/mana не объявляются совпавшими. Будущий сохраняемый CLI/importer требует отдельной спецификации; этот эксперимент не подключается к игре.
