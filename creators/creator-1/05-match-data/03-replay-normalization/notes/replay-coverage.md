# C1-05-03: покрытие реплеями (решение и сопоставление)

Дата: 13 октября 2026.

## Решение по парсеру

Реплеи недоступны: совместимый парсер не выбирался, версия не фиксировалась —
выдумывать парсер запрещено правилами. Правило нормализации (`src/replay_gate.py`,
`c1-replay-gate-v1`) определено заранее и проверено на синтетических событиях
(тесты 4/4 OK): наблюдаемое действие отделяется от предполагаемого намерения
(`intent_is_guess=true`), будущие/скрытые записи отбрасываются.

## Следствие

Персонализация ограничена явно: без событий реплеев профили C1-06-01
строятся только на агрегатах ленты и помечаются accordingly
(покрытие низкое, неопределённость высокая).

## Сопоставление с критерием

Критерий «нормализация воспроизводится» выполнен для правила (детерминированный
гейт с версией). Критерий «при отсутствии событий персонализация ограничена
явно» выполнен этой записью. Не проведено: сверка выбранных событий с реальным
матчем (событий нет), выбор парсера, приёмка вторым создателем.
