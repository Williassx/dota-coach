# C1-05-01: аудит источника dota2.ru (веб-исследование)

Дата: 13 октября 2026. Метод: веб-исследование доступности и опубликованных
правил; массовая загрузка данных не выполнялась. Это не юридическое заключение;
юридический разбор ведут отдельные роли по [документам](../../../docs/legal/plan.md).

## Подтверждено

- Сайт dota2.ru доступен: главная, матч-центр (`esport/matches`) и `robots.txt`
  вернули HTTP 200; часть текста страниц отрисовывается динамически, полнота
  и стабильность данных этой проверкой не установлены.
- Опубликованного API и условий, регулирующих автоматический сбор данных
  матчей, не найдено; проверенные адреса `/terms/` и `/rules/` дали 404.
  Отсутствие страниц по этим адресам не доказывает отсутствия любых условий и
  не является отказом правообладателя.
- `robots.txt` ограничивает ряд путей (`Disallow: /*?*` с отдельными Allow для
  фильтров матчей). Это правила для поисковых роботов, а не разрешение на сбор.

## Альтернативные источники (факты, без завышения лимитов)

- STRATZ API: отдельная API-страница и база знаний существуют; точные текущие
  квоты в проверке подтвердить не удалось (страницы не извлеклись).
- Steam Web API: требуется ключ; общий лимит по Steam Web API Terms —
  100 000 вызовов в сутки; интерфейс `IDOTA2Match_570` / `GetMatchHistory`
  описан сторонним справочником xPaw, в официальной документации метод
  не задокументирован; проверка endpoint без ключа вернула 403 — это не
  доказательство его отсутствия.
- OpenDota: документация и открытые данные существуют; историческое объявление
  2018 года упоминает лимит 50 000 вызовов/месяц — не считать текущим.

## Права Valve

- Steam Subscriber Agreement: контент лицензируется, не продаётся; использование
  ограничено личными некоммерческими целями; есть запрет автоматизации
  взаимодействия со Steam — автоматически не приравнивается к запрету
  документированного API, его применение отдельно рассматривают Steam Web API Terms.

## Выводы для C1-05-01

Приоритет исследования — документированные интерфейсы (STRATZ/OpenDota/Steam Web API
с ключом). Для dota2.ru фиксируются: доступность страниц, ограничения robots.txt,
отсутствие найденного публичного API. Агрегаты не называть данными микродействий.

## Фактические образцы (13 октября 2026)

OpenDota отвечает публично без ключа, но отклоняет запросы без обычного User-Agent
(первый запрос — HTTP 403, после добавления User-Agent — 200). Собрано два малых
образца: агрегаты героев (heroStats) и лента публичных матчей (publicMatches)
с описанием происхождения и полей в [fixtures/README.md](../fixtures/README.md).
Лента отдаёт и незавершённые матчи — фильтр `duration > 0` перед импортом.

dota2.ru: получены robots.txt целиком (1753 байта) и мета-срез страницы матч-центра
`/esport/matches/` (полная страница 259 592 байта, в фикстуре — первые 8192 байта
и SHA256 полной страницы; полный HTML в фикстурах не хранится).
Факты разметки: в статическом HTML — 58 ссылок на `esport/match/<id>`
(43 уникальных), ссылок `teams/<id>` нет — данные команд рендерятся динамически.
Вывод: списки матчей и их ID доступны статически; парсинг страниц возможен,
но полнота работы через HTML нестабильна; приоритет остаётся за документированными API.
Агрегаты по-прежнему не называть данными микродействий; сохраняемые пакеты —
только ID матчей, без персональных данных.

## Сопоставление с критерием и непроведённые проверки

Критерий «есть образец с происхождением либо конкретный отказ» выполнен:
четыре малых образца с происхождением (OpenDota ×2, dota2.ru ×2) плюс
зафиксированные отказы/ограничения (403 без User-Agent, динамическая
разметка команд, отсутствие найденного публичного API dota2.ru).
Агрегаты нигде не названы данными микродействий; целостность образцов
закрыта тестами `tests/test_fixtures_integrity.py` (6/6 OK).
Не проведено: поле патча в ленте отсутствует (пропуск для C1-05-02);
образцы полей страниц отдельных матчей dota2.ru не собирались;
юридическая оценка — за ролями 161–172 по [документам](../../../docs/legal/plan.md).
Передача создателю 2 не выполнена.
