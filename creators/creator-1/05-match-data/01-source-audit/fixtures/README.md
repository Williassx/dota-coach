# Фикстуры C1-05-01

Малые разрешённые примеры с явным происхождением; реальные массовые данные
здесь не хранятся. Оба образца — агрегаты/публичные сводки, не данные
микродействий конкретных людей; имена игроков не сохранялись.

## opendota-herostats-sample.json

- Источник: публичный `GET https://api.opendota.com/api/heroStats`
  (без ключа; 13 октября 2026).
- Срез: `record_count: 127` (все герои на момент запроса), сохранены 3 записи
  и 25 первых полей каждой (поля отсортированы по имени).
- Наблюдённые группы полей: pick/win по bracket-ам (`1_pick..8_win`,
  напр. `5_pick: 143758`), базовые атрибуты роста (`agi_gain: 2.8`),
  тайминги атаки (`attack_point: 0.3`). Полный список полей не зафиксирован;
  не называть эти агрегаты данными микродействий.

## opendota-publicmatches-sample.json

- Источник: публичный `GET https://api.opendota.com/api/publicMatches`
  (без ключа; тот же день). Ответ держит 100 последних публичных матчей;
  сохранены 5 записей целиком — они уже компактные, персональных идён нет.
- Наблюдённые поля: `match_id`, `match_seq_num`, `radiant_win`, `start_time`
  (unix-сек), `duration` (сек; 0 у незавершённых), `lobby_type`, `game_mode`,
  `avg_rank_tier`/`num_rank_tier`, `cluster`, `radiant_team`/`dire_team`
  (по 5 ID героев; у незавершённых — нули).
- Наблюдение протокола: лента отдаёт и незавершённые матчи; перед импортом
  в C1-05-02 фильтр `duration > 0` и валидные списки команд.
- Пропуск: поля патча в записях ленты нет — версия патча матча этим образцом
  не устанавливается; источник патча — задача C1-05-02 (закрыто тестом
  `test_unfinished_matches_visible_for_filter` как напоминание о фильтре).

## dota2ru-robots.txt

- Источник: `GET https://dota2.ru/robots.txt`, 13 октября 2026, целиком
  (1753 байта) — официально публичный файл правил для роботов.
- Ссылка в аудит: общий `Disallow: /*?*` с Allow для фильтров матчей
  (`/esport/matches/?team=*`, `?tournament=*`), отдельные запреты `/find/`,
  `?tbd` матчи, `/privacy/` и личностные разделы форума.

## dota2ru-matches-page-head.json

- Источник: `GET https://dota2.ru/esport/matches/` 13 октября 2026.
- Сохранены: URL, SHA256 полной страницы (259 592 байта) и первые 8192 байта;
  полный HTML в фикстурах не хранится.
- Факты разметки: 58 ссылок на `esport/match/<id>` (43 уникальных) в статическом
  HTML; командных ссылок там нет — они рендерятся динамически.

## Отказ от массовости

Оба dota2.ru-образца — единичные загрузкиCV небольшой суммарный объём;
без параллельных запросов и обхода. Перед следующим сбором — сверка с robots.txt
и повторная проверка условий источника.
