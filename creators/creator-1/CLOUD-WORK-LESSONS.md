# Уроки облачной смены C1, 13 октября 2026

Рабочие заметки проекта (не веса модели, не глобальная память).

1. Факт: `git commit` забирает весь staged-индекс, включая чужие
   пред-staged файлы. Причина первого сбоя: проверил только хвост
   `diff --cached --stat`, в коммит уехали 3 файла C2.
   Подход: перед коммитом смотреть полный `diff --cached --name-only`
   и сверять каждую строку с границей задачи. Проверка: повторный
   `git diff HEAD~1 HEAD --name-only` (именно двухаргументный).
2. Факт: `git diff <commit>` без второго аргумента сравнивает с деревом,
   а не с HEAD — ложная тревога «3 не-C1». Причина: неверная команда
   проверки. Подход: для сравнения коммитов всегда два аргумента.
3. Факт: `Path.parents[0]` — непосредственный родитель; для tests/
   корень C1 — `parents[2]`, не `parents[3]`. Проверка: assert на импорт.
4. Факт: `read_text()` без encoding на Windows ломает кириллицу тестов
   (cp1251). Подход: всегда `encoding="utf-8"`; lesson уже применялся
   в новых тестах смены.
5. Факт: Lua-интерпретатора в облаке нет (`which lua*` пуст) — Lua-файлы
   проверяются только статически; это ограничение записано, а не обойдено.
