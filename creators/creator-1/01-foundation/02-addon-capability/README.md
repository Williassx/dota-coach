## Результат и приёмка

Реальный клиент выполняет движение и атаку; лог и наблюдение подтверждают идентичность героя.

Подготовка C1-01-02 и C2-01-02 начинается после соответствующих аудитов; затем
авторы совместно проверяют событие и подтверждение, изменяя разные серверные/UI
файлы. Завершение UI заранее не требуется для начала серверной работы.
Это проверка механизмов. Полный цикл ИИ/мышь/возврат принимается позже по
[распределению сценариев](probe-design.md), а не закрывается этой карточкой.

## Где размещать материалы

- `probe-design.md` — материал данного подпункта.

- `src/` — единственные исходники данного подпункта.

Это назначение будущих файлов, а не заявление, что все они уже созданы.
Новый вложенный каталог получает README с назначением и ссылкой из этого файла.
API, сигнатуры, конкретные файлы и команды проверки закрепляются в локальном
техническом плане после исследования входов; не подменяйте их выдуманными командами.
