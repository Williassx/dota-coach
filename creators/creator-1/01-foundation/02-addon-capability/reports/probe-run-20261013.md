# C1-01-02: первый нативный прогон (r1, 13 октября 2026)

Пользователь подтвердил использование компьютера под задачи создания кастомки.
Установка и запуск выполнены отдельным шагом по сценарию
[tools/probe-command.ps1](../tools/probe-command.ps1), который следует
проверенному рецепту создателя 2 (карта — из content-шаблона, addoninfo — из
workshop_testbed, компиляция в game-аддон).

## Собственные файлы прогона

- `build/dota_coach/np-c1-probe-r1-20261013-map-compile.log`
- `build/dota_coach/np-c1-probe-r1-20261013-console.log`
- `build/dota_coach/np-c1-probe-r1-20261013-owned.json` (pid 24752; клиент
  завершён тем же сценарием: quit exit=0; после этого dota2.exe в списке
  процессов отсутствует).

## Подтверждено фактами журнала

- Компиляция карты: resourcecompiler exit=0 (1/0) на нашем аддоне `dota_coach_c1_probe_20261013`;
  карта — копия `content/dota_addons/addon_template/maps/template_map.vmap`.
- Запуск: скрытый клиент 1280×720 с `-game <...>/game/dota -steam -addon
  dota_coach_c1_probe_20261013 ... +dota_launch_custom_game dota_coach_c1_probe_20261013 template_map`.
- Серверный Lua активирован: `D1C102 precache` (09:51:15) и `D1C102 activated`
  (09:51:23) в [VScript] журнале. Записи SteamAudio/trophies — штатные
  предупреждения запуска, к нашему сценарию не относятся, их не глушили.
- Фазы карты: CUSTOM_GAME_SETUP → HERO_SELECTION → WAIT_FOR_MAP_TO_LOAD →
  PRE_GAME (09:54:09) → GAME_IN_PROGRESS (09:55:39).
- Серверная логика: создан герой `npc_dota_hero_sniper` (союзный) и второй юнит
  той же модели на `DOTA_TEAM_BADGUYS`; журнал содержит
  `D1C102 identity hero=npc_dota_hero_sniper target=npc_dota_hero_sniper`.
  Повторное создание юнита не произошло — повторный вызов CreateUnits не производился.
- Приказ движения исполнился: позиция героя изменилась
  `origin (-559.69, -440.31)` → `(-128, -64)` по тикам наблюдения (47 записей `D1C102 state`).
- Затем выдан приказ атаки (`D1C102 order attack issued`), один, повторов нет.

## Непроведённые (не объявлять выполненными)

- Событие Panorama и «сервер → UI» подтверждение — предмет пары с C2-01-02;
  здесь только сервер и лог.
- Исполнение атаки фактами лога не подтверждено: цель не была убита за время
  прогона (записей об убийстве нет). Возможный следующий шаг сценария:
  периодический вывод здоровья цели.
- Передача управления реальному игроку и «чужой/повторный приказ» не проверялись;
  это предмет C1-01-03.
- Визуальная приёмка человеком не проводилась (WindowStyle Hidden).

## Урок проекта

`(GameRules:State_Get() == DOTA_GAMERULES_STATE_GAME_IN_PROGRESS)` не наступает
сразу после `+dota_launch_custom_game`: до него прошло около 4 минут (первые
~1,5 мин — авто-фазы setup/hero selection/strategy). Think-логику фазового
тайминга проектировать с учётом этих фаз; состояния читать из журнала, а не
предполагать по моменту запуска.

Карта шаблона живёт по **content** пути (`content/dota_addons/addon_template/maps/`);
предустановленный game-аддон шаблона каталога maps не содержит. Это же проясняет
раннюю ошибку ERROR_FILEOPEN при сборке карты у создателя 2.
