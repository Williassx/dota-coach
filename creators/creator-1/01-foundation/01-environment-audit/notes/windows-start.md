# Продолжение C1-01-01 на Windows

Целевая папка: `D:\AI\dota2coach`. Облачная сессия работает в Linux и не имеет
подключённого диска D: или Windows-терминала. Команды ниже ещё не выполнялись на
компьютере пользователя; локальное клонирование не объявляется завершённым.

## Клон

В локальном терминале Codex или PowerShell, если папка новая/пустая:

```powershell
git clone https://github.com/Williassx/dota-coach.git D:\AI\dota2coach
```

Если папка содержит файлы, сначала проверьте их. Существующий клон не клонируется
повторно; другие файлы не удаляются и не сбрасываются. Локальный агент проверяет
верхний каталог Git, origin через помощник и наличие пользовательских изменений
перед любым обновлением. При отсутствии Git нужна установленная Git for Windows;
облачный Git не означает наличие Git на компьютере пользователя.

## Запуск обследования

Откройте папку как локальный проект Codex. Нужен Python 3.9+; используйте доступный
на этой машине `python` или эквивалентный запуск через `py -3`.

```powershell
Set-Location D:\AI\dota2coach
python .\creators\creator-1\01-foundation\01-environment-audit\tools\inspect_environment.py --repository . --output .\creators\creator-1\01-foundation\01-environment-audit\reports\windows-local.json
```

Без `--output` JSON выводится в терминал. Существующий файл помощник не заменяет;
для повторного отчёта выберите новое имя, заканчивающееся `-local.json`.
При ненайденном Steam можно передать `--steam-root "<фактическая папка Steam>"`.
Проверить установки Python/Git должен локальный агент; автоматически они не устанавливаются.

Отчёт читает манифест и каталоги. Наличие этих файлов не доказывает работоспособность
Workshop Tools. Реальная версия клиента, загрузка шаблона, серверный лог и Panorama
подтверждаются следующим локальным обследованием/запуском. Не публикуйте сырой отчёт,
если в путях есть ненужные персональные сведения.

> Работаем в D:\AI\dota2coach, создатель 1, C1-01-01. Прочитай корневой AGENTS.md,
> creators/creator-1/AGENTS.md, PLAN.md и README подпункта. Начинай все заметки
> в creators/creator-1/01-foundation/01-environment-audit. Сохрани существующие файлы
> и пользовательские изменения. Проверь клон ожидаемого репозитория и выполни
> tools/inspect_environment.py, если есть Python 3.9+. Найди фактические Steam-библиотеки,
> game/content, шаблон аддона и возможности получения логов. Отделяй найденные определения
> API от проверенной работы движка. Если Python отсутствует, составь тот же аудит
> чтением манифестов и штатными командами без автоматической установки программ.
