# C1-01-01: обследование среды

Пользователь поручил начать первый подпункт создателя 1 и указал Windows-путь
`D:\AI\dota2coach`. Цель — получить факты о доступной среде и подготовить локальное
обследование; Steam/Dota, пользовательские файлы и права GitHub не изменяются.

Помощник на Python 3.9+ со стандартной библиотекой читает состояние указанного Git-клона,
находит только выбранные библиотеки Steam и читает манифест Dota 2. В Windows пути
Steam берутся из известных реестровых ключей или явного параметра. Не запускает игру,
не клонирует репозиторий и не вызывает сеть. Клонирование — отдельная команда Git.

JSON содержит ОС, версии Python/Git, HEAD, ветку, признак изменений и соответствие
origin ожидаемому репозиторию. Сырой origin, учётные данные и полное окружение не выводятся.
Манифест сообщает сборку и наличие каталогов, но не доказывает установку/запуск Tools.
В Linux Windows-путь имеет статус недоступного из этого runtime. Найденные файлы
не считаются успешной проверкой героя, событий Panorama или управления мышью.

По умолчанию отчёт выводится в stdout; с `--output` создаётся новый файл. Существующий
файл отчёта не заменяется. Локальные JSON исключены из Git. Итоговое резюме в Markdown
можно включить в Git после удаления ненужных персональных сведений.

Приёмка: помощник проверен на реальных временных Git-репозиториях и файловых примерах
Steam, сохраняет существующие отчёты, не раскрывает учётные данные origin и не меняет
обследуемые файлы. Локальный запуск Windows и реальная сцена остаются отдельными проверками.
