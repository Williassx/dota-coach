# C1-01-01: план первого обследования

> Для агентной работы: выполнить здесь согласованное обследование; использовать
> `superpowers:executing-plans` и проверки поведения диагностического помощника.

**Цель:** зафиксировать доступную среду и подготовить воспроизводимое обследование Windows.
**Архитектура:** один читающий помощник, малые файловые примеры Steam и реальные временные
Git-репозитории для проверок; отчёты отделены от исходников.
**Технологии:** Python 3.9+, unittest, Git; внешних Python-пакетов нет.
**Спецификация:** [design.md](design.md).

## Ограничения

- Целевой клон Windows: `D:\AI\dota2coach`; ожидаемый репозиторий — Williassx/dota-coach.
- Помощник не клонирует, не изменяет Steam/Dota, не запускает игру и не вызывает сеть.
- Сырой origin и значения окружения не попадают в отчёт.
- Существующий файл отчёта не заменяется.

## Фокус проверки

Отсутствующие game/content не доказывают готовность Tools; манифест может остаться
после удаления игры. Путь installdir вне Steam common не обследуется. Origin может
содержать учётные данные. Изменения клона сохраняются. Запись отчёта не портит старый файл.

## Задача 1: факты и помощник

**Файлы:** `tools/inspect_environment.py`, `tests/test_inspect_environment.py`,
`reports/cloud-audit.md`, `notes/windows-start.md`.
**Входы:** путь Git-репозитория и явно выбранные/обнаруженные пути Steam.
**Выходы:** JSON с фактами и статусом `runtime_verified: false`.
**Интерфейсы:** `steam_libraries(root: Path) -> list[Path]`,
`inspect_dota_library(library: Path) -> dict`, `inspect_git(repository: Path) -> dict`,
`build_report(repository: Path, steam_roots: list[Path]) -> dict`.
