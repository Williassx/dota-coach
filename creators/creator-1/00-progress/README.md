# Как считается прогресс создателя 1

Совести принцип тот же, что у создателя 2: доля отмеченных действий
(`- [x]` против `- [ ]`) в чек-листах `## Действия` всех README подпунктов
разделов 01–12. Это доля отмеченных действий, не оценка времени, качества или
готовности кастомки: готовые исходники не закрывают нативную проверку и
приёмку второго создателя.

## Отчёты

- `progress.json` — машинный разрез (разделы/подпункты/числа).
- `PROGRESS.md` — человеческий обзор с таблицей разделов.
- `progress.svg` — горизонтальная диаграмма «разделы 01–12, шкала 0–100%»,
  собирается индивидуальным генератором (стандартная библиотека Python,
  без внешних пакетов; уже существующие файлы генератор перезаписывает —
  это его единственная роль, файлы отчётов и код он не меняет).

## Обновление

```bash
python creators/creator-1/00-progress/tools/update_progress.py
```

Проверочное чтение без записи: тот же скрипт c `--check` (возвращает код 2,
если выходы устарели).
