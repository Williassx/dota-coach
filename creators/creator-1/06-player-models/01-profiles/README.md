## Результат и приёмка

Профиль имеет версии и границы; характер не объявлен доказанным по агрегатам.
Разбиение и протокол оценки закреплены до вычисления/настройки признаков и модели;
преобразования обучаются на train, выбор вариантов — на validation. Итоговый test
не открывается для настройки C1-06-01/C1-06-02.

## Где размещать материалы

- `src/` — единственные исходники данного подпункта.
- `tests/` — проверки поведения и отказов.
- `notes/profile-schema.md` — решения и исследования.
- `notes/evaluation-protocol.md` — ранний протокол и неизменяемое разбиение до настройки признаков.

Это назначение будущих файлов, а не заявление, что все они уже созданы.
Новый вложенный каталог получает README с назначением и ссылкой из этого файла.
API, сигнатуры, конкретные файлы и команды проверки закрепляются в локальном
техническом плане после исследования входов; не подменяйте их выдуманными командами.
