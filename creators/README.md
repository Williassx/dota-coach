# Рабочие библиотеки создателей

Все новые задания начинаются в папке своего создателя, затем раздела и подпункта.
В этой же папке остаются исследования, единственные исходники, проверки и результаты.

| Равноправный владелец | Отдел | План | Первый подпункт |
|---|---|---|---|
| Создатель 1 | Сервер, ИИ, данные, правила исполнения | [36 подпунктов](creator-1/PLAN.md) | [C1-01-01: среда](creator-1/01-foundation/01-environment-audit/README.md) |
| Создатель 2 | Интерфейс, карта, мышь, голос | [36 подпунктов](creator-2/PLAN.md) | [C2-01-01: локальная библиотека](creator-2/01-foundation/01-workspace-audit/README.md) |

В каждом отделе 12 разделов; Git сохраняет все 72 папки подпунктов через их README.
Это план работ: существование папки не означает реализованную функцию.

- [Правила библиотеки и добавления новых папок](shared/WORKFLOW.md).
- [Общие контракты](shared/contracts/README.md).
- [Интеграция исходников в аддон](shared/INTEGRATION.md).
- [Подтверждённые решения проекта](../docs/decisions.md).

Статусы задач находятся только в README подпунктов. Общие файлы имеют одного автора
на задачу и второго проверяющего; после необходимых проверок объединить изменение
может любой создатель. Каталог не назначает кому-либо старшие права.
