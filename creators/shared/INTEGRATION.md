# Интеграция библиотек в аддон Dota Coach

Работа начинается в папках создателей; конечная структура Dota не отменяет это правило.
До локального аудита установка аддона и пути Workshop Tools не объявляются известными.

## Один источник каждого файла

1. Сервер/ИИ/данные редактируются у создателя 1, Panorama/карта/голос — у создателя 2.
2. Общие контракты находятся в `creators/shared/contracts`.
3. В C2-11-02 оба владельца рассматривают manifest: исходный файл → относительный
   файл аддона → назначение → способ получения/сборки → ответственный.
4. Сборка создаёт отдельный каталог `build/dota_coach/`, исключённый из Git.
   В нём не ведут разработку вручную. Любое исправление возвращается к исходнику.
5. Установка этого пакета в фактические `game/dota_addons` и `content/dota_addons`
   выполняется отдельным явным действием после проверки путей и существующих файлов.

Manifest должен запрещать два разных исходника для одного конечного пути. Панорама,
компиляция карты и автоматически создаваемые файлы определяются по реальному шаблону;
нельзя считать весь каталог `game` областью создателя 1, а весь `content` — создателя 2.
Существующие аддоны и пользовательские изменения не заменяются автоматически.

Первую небольшую сцену можно упаковать по собственному рассмотренному плану раньше
C2-11-02. Полный сборочный процесс развивается после этой проверки, без создания
преждевременных runtime-копий или выдуманной команды сборки.
