# Проверка организации работы пятью критиками

Проверено 9 октября 2026 года перед публикацией структуры. Критики читали изменения
независимо; файлы редактировал основной исполнитель. Это техническая проверка,
а не подмена рассмотрения вторым владельцем.

| Критик | Подтверждённая проблема | Исправление |
|---|---|---|
| Объём | Ранняя проверка API смешана с полной сценой возврата ИИ | Общая спецификация сцены распределяет приёмку по C1-01, C1-03, C1-04 и C2-05 |
| Архитектура | UI ожидал серверный механизм, сервер — уже проверенный UI | Начальная Panorama подготавливается совместно в разных файлах; зависимости MANUAL/состава направлены от серверного механизма к UI |
| ИИ | Разбиение матчей было после настройки признаков/политики | В C1-06-01 протокол и train/validation/test закрепляются до настройки; C1-06-03 только проводит итоговую оценку |
| Интерфейс | Не назначен ранний серверный обработчик подтверждения | Создатель 1 делает обработчик в C1-01-02, создатель 2 — панель C2-01-02; проверки выполняются совместно |
| Осуществимость | `git status` мог обновлять индекс в читающем помощнике | Все Git-вызовы используют `--no-optional-locks`; тест отслеживаемого файла воспроизвёл проблему, затем прошёл |

Критик интерфейса предложил включить все сценарии возврата в приёмку C1-01-02.
Вместо этого сохранена граница задач: C1-01-02 проверяет механизмы; полная сцена
обязана пройти всю таблицу после C1-04-03/C2-05-03. Иначе контракт и возврат
потребовались бы до задач их реализации.

Подтверждены: библиотеки 12×3 для каждого, разделение отделов, единственные исходники,
сохранение голоса, цифровых игроков, подготовки и временного вмешательства.
Windows-клон и работа Dota не объявлены выполненными. Проверка ссылок, зависимостей
и восемь тестов помощника выполняются отдельно основным исполнителем.
