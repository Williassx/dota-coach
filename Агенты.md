# Агенты — быстрый каталог Dota Coach

175 ролей для разработки игры. Этот файл служит быстрым индексом; полные правила
и обязанности поддерживаются в [docs/agents.md](docs/agents.md).
Инструкции работы с репозиторием находятся в [AGENTS.md](AGENTS.md).
Роли описывают специализации и не запускают 175 процессов автоматически.

## Быстрый выбор

| Задача | Роли |
|---|---|
| Состав агентов и экономия токенов | 173–175 |
| Координация и границы первой версии | 1, 5, 7, 151 |
| Источники матчей и модель игрока | 21, 23, 40, 51, 102, 142 |
| Симуляция и карта | 36, 41–50, 57 |
| Голосовые приказы и ручное вмешательство | 61, 69, 73, 76, 77, 131, 156 |
| Подготовка и отношения в команде | 22–26, 126–130 |
| Экран и карточки | 71–80 |
| Проверки и воспроизводимость | 50, 111–119, 141–145, 150 |
| Valve, материалы, данные и права игроков | 161–172; аудит контента — 120 |

[Экономный порядок](creators/shared/AGENT-EFFICIENCY.md): обсуждение без подагентов,
критик только в конце подпроекта. Роли 173–175 обычно выполняет основной исполнитель.

## Как поручить задачу

Укажите роль по номеру, результат, входные документы, область изменений и проверку.
Например: «Подключи агента 162 для исследования условий Valve по LGL-002».
Исполнитель читает соответствующие документы и подтверждает доступность источников.

```text
Роль: 162 — лицензирование Valve и Dota 2.
Задача: исследовать основания использования оригинальных материалов для Dota Coach.
Вход: docs/project-brief.md, docs/legal/plan.md, docs/legal/initial-review.md.
Результат: таблица документов, условий, неизвестных вопросов и следующих действий.
Ограничения: не выдавать непрочитанные условия за проверенные; никому не писать.
Проверка: у каждого вывода есть источник, дата и статус доступности.
```

Поиск из корня репозитория:

```bash
rg '^\| 162 \|' Агенты.md
rg -n 'голос|ИИ|Valve|данн' Агенты.md
```
